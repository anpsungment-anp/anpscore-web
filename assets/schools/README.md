# โลโก้โรงเรียน

วางไฟล์โลโก้ไว้ในโฟลเดอร์นี้ โดยตั้งชื่อไฟล์ให้ตรงกับ `id` ในรายการของ
[app/school-orbit.js](../../app/school-orbit.js) — ตราบใดที่ยังไม่มีไฟล์
วงโคจรจะแสดงวงกลมอักษรย่อแทนให้อัตโนมัติ ไม่พัง

## ข้อกำหนดไฟล์

- นามสกุล `.png` (ถ้าใช้นามสกุลอื่น ส่งผ่าน `ext` ตอนเรียก `renderSchoolOrbit`)
- **พื้นหลังโปร่งใส** และครอปขอบขาวรอบ ๆ ออกให้ชิดตัวตรา
- จัตุรัส ประมาณ 512×512 px

## เพิ่ม ลบ หรือแก้ชื่อโรงเรียน

แก้ที่อาร์เรย์ `window.SCHOOL_ORBIT_LOGOS` ใน `app/school-orbit.js` ที่เดียว
จำนวนวงโคจรและระยะห่างจะคำนวณใหม่ให้เอง
