## ขั้นที่ 1 — ขอเพิ่มโควตาโปรเจกต์

บัญชี `anpsungment@gmail.com` มีโปรเจกต์ครบ 20 ตัวแล้ว สร้างเพิ่มไม่ได้

```
The project cannot be created because you have exceeded your allotted project quota.
```

กรอกฟอร์มขอเพิ่มที่

<https://support.google.com/code/contact/project_quota_increase>

กรอกประมาณนี้

- **Billing account / Project ID** — ใส่โปรเจกต์ที่มีอยู่ เช่น `anpscore-system`
- **จำนวนที่ขอ** — ขอสัก 40 เผื่อไว้
- **เหตุผล** — ระบบบริหารจัดการผลการเรียนของโรงเรียน ต้องแยกโปรเจกต์ใหม่เพื่อยกระดับความปลอดภัย

ปกติอนุมัติภายใน 1–2 วันทำการ และไม่มีค่าใช้จ่าย

> ถ้าไม่อยากรอ ใช้โปรเจกต์ที่เลิกใช้แล้วแทนได้ ด้วย `--skip-create`
> (ดูขั้นที่ 2) แต่ต้องมั่นใจว่าโปรเจกต์นั้นไม่มีใครใช้อยู่จริง

## ขั้นที่ 2 — ตั้งค่าโปรเจกต์และ deploy

รันคำสั่งเดียว ทำครบตั้งแต่สร้างโปรเจกต์จนขึ้นเว็บ

```bash
node scripts/bootstrap-project.mjs anpscore-2569
```

สคริปต์นี้จะ

1. สร้างโปรเจกต์ `anpscore-2569`
2. สร้างฐานข้อมูล Firestore ที่ `asia-southeast1` (สิงคโปร์ ใกล้ไทยที่สุด)
3. ลงทะเบียนเว็บแอปและดึงค่าตั้งค่ามาเขียนลง `auth/firebase-config.js` ให้อัตโนมัติ
4. ตั้ง `.firebaserc` ให้ชี้โปรเจกต์ใหม่
5. deploy กฎความปลอดภัย index และหน้าเว็บ

รันซ้ำได้ถ้าติดขัดกลางทาง ขั้นที่ทำไปแล้วจะถูกข้าม

ถ้าใช้โปรเจกต์ที่มีอยู่แล้วแทนการสร้างใหม่:

```bash
node scripts/bootstrap-project.mjs <projectId ที่มีอยู่> --skip-create
```

## ขั้นที่ 3 — สองอย่างที่ต้องกดเองในคอนโซล

Firebase CLI ทำสองอย่างนี้แทนไม่ได้

**1. เปิดการเข้าสู่ระบบด้วยอีเมล**

`https://console.firebase.google.com/project/anpscore-2569/authentication/providers`
→ Email/Password → Enable → Save

**2. ดาวน์โหลดกุญแจสำหรับเครื่องมือผู้ดูแลระบบ**

`https://console.firebase.google.com/project/anpscore-2569/settings/serviceaccounts/adminsdk`
→ Generate new private key

เก็บไฟล์ไว้ **นอก** โฟลเดอร์โปรเจกต์ และห้าม commit

## ขั้นที่ 4 — ย้ายข้อมูลและสร้างบัญชี

```bash
$env:GOOGLE_APPLICATION_CREDENTIALS = "C:\path\to\key.json"
```

ซ้อมก่อนหนึ่งรอบ ไม่ต้องมีกุญแจและไม่เขียนอะไรเลย

```bash
node tools/migrate-project.mjs import anpscore-2569 --dry-run
```

จะตรวจให้ว่ารหัสครูซ้ำกันไหม ประกอบเป็นอีเมลได้ทุกคนไหม รหัสเอกสารถูกต้องไหม
และ core_db เกินเพดาน 1 MB ของ Firestore หรือเปล่า ถ้าผ่านค่อยย้ายของจริง

```bash
node tools/migrate-project.mjs import anpscore-2569
```

คำสั่งนี้จะเขียนข้อมูลทั้งหมดลงโปรเจกต์ใหม่ สร้างบัญชี Firebase ให้ครูทุกคน
โดยใช้รหัสผ่านเดิมของแต่ละคน แล้วลบรหัสผ่านออกจากฐานข้อมูลให้เรียบร้อย

จากนั้นสร้างบัญชีผู้ดูแลระบบ (ใช้รหัสใหม่ อย่าใช้ `0918586632` เดิม)

```bash
node tools/anpscore-admin.mjs create-admin <รหัสผ่านใหม่>
```

ตรวจผล

```bash
node tools/anpscore-admin.mjs list
```

## ขั้นที่ 5 — ตรวจสอบ

เว็บใหม่อยู่ที่ `https://anpscore-2569.web.app`

- เปิดในหน้าต่างไม่ระบุตัวตน ต้องเห็นหน้าเข้าสู่ระบบ และไม่มีการเรียก Firestore ก่อนล็อกอิน
- เปิด `/pp1.html` และ `/schedule.html` ตรง ๆ ต้องถูกพากลับมาหน้าเข้าสู่ระบบ
- ล็อกอินเป็นครูด้วยรหัสผ่านเดิม ต้องเข้าได้และเห็นคะแนนครบ
- ลองกรอกคะแนนหนึ่งช่อง แล้วรีเฟรช ต้องยังอยู่

เมื่อมั่นใจแล้ว **ลบไฟล์ `.migration/anpscore-export.json` ทิ้ง** เพราะมีรหัสผ่านครูอยู่ข้างใน

## เรื่องที่ยังค้าง

1. **โปรเจกต์เดิมยังเปิดให้คนนอกอ่านข้อมูลนักเรียนได้**
   ตราบใดที่ `anpscore-system` ยังเปิดอยู่ ช่องโหว่เดิมยังอยู่
   เมื่อระบบใหม่ใช้งานได้แล้ว ควรปิดของเดิมด้วยการ deploy `firestore.rules` ที่ปิดทุกอย่างขึ้นไป

2. **`school-survey-2569` ยังไม่ได้แก้**
   `pp1.html` อ่านเลขบัตรประชาชนและข้อมูลบิดามารดาจากโปรเจกต์นั้นโดยไม่ล็อกอิน
   เป็นคนละโปรเจกต์ ต้องเข้าไปตั้งกฎแยกต่างหาก

3. **`pp1.html` ยังไม่ได้แยกไฟล์**
   ยังเป็นไฟล์เดียว 3,982 บรรทัด เหมือนที่ `index.html` เคยเป็น
